# 远程电视播放器 1.2.2（老电视兼容版）

从 `http://82.156.239.39/movie.txt` 获取视频直链并自动播放。使用内置 LibVLC 3.7.7，包含 HEVC 与 E-AC-3 软件解码器，并通过 OpenSL ES 输出 PCM 音频。

## 安装包选择

- **RemoteTVPlayer-arm32.apk**：armeabi-v7a，优先供老款海尔等 32 位 ARM 电视尝试。
- **RemoteTVPlayer-arm64.apk**：arm64-v8a，供 64 位 ARM 设备使用。
- **RemoteTVPlayer.apk**：通用包，含 ARM32、ARM64、x86、x86_64，体积较大。

最低系统要求 Android 4.2 / API 17；APK 启用 V1（JAR）和 V2 签名。Android 4.2 以下、非安卓系统或不支持这些 CPU 架构的电视仍无法安装。电视型号未知时，不能保证一定适配。
下载 `.apk` 原文件后安装，不要把 Actions 下载的 ZIP 直接交给电视安装器。若仍提示“解析程序包时出现问题”，核对文件是否下载完整，以及电视“设置 → 关于本机”中的系统版本。发布页提供 SHA256 校验值。

## 遥控器

| 播放时按键 | 功能 |
| --- | --- |
| ↑ | 打开字幕、音轨与解码设置 |
| ↓ / 确定 | 暂停、继续 |
| ← / → | 快退、快进 10 秒，可长按 |
| 返回 | 关闭菜单或退出 |

菜单内 ↑ ↓ 选项目，← → 调整或执行；“返回播放”一行可以只用方向键退出菜单。菜单可上下滚动，小屏也能选到所有项目。

## 黑屏或没有声音时

解码与画面输出分别选择，不再绑定：

- 解码：硬解优先（允许回退）、软件解码（限制为 2 个 FFmpeg 解码线程）。保留软件音频解码，不用全局“仅硬解”白名单限制 E-AC-3 音频。
- 画面输出：OpenGL + Surface（默认）、原生 Surface、OpenGL + Texture。硬解和软解都可以切换输出方式。

OpenGL 在同一路画面输出中合成字幕；原生 Surface 使用独立字幕层。旧版软解 Texture 选项升级后会拆成软件解码 + Texture。切换输出方式会释放旧内核再创建新输出，不同时运行两份播放器。不修改源视频的分辨率或位深。

菜单底部显示视频解码 / 显示帧数，以及音频解码 / 输出缓冲计数。字幕能显示不代表视频和音频已成功解码；这些计数能帮助定位问题。
PCM 音频输出不依赖电视或 HDMI 接收设备对 E-AC-3 直通的支持。软件解码仍受 CPU 性能限制，接近 4K 的 10-bit 视频可能卡顿；更换 1080p H.264 + AAC 片源是另一种兼容办法。

## 4K 稳定性与解码资源

1.2.2 移除了 3 / 10 / 20 秒额外缓存选项及其设置，不增加网络缓存，不整部下载或做磁盘影片缓存。流式播放仍需要内核正常的少量缓冲；文件 30 GB 不等于占用 30 GB 内存。

软解显式限制为 2 个 FFmpeg 解码线程，减少并行解码带来的帧缓冲数量。默认使用 OpenGL + Surface 输出；模式名称表示选择策略，不证明设备实际使用了硬件解码。软解性能不足时仍可能卡顿，不能用降低播放器输出分辨率来替代源视频解码。

- 播放错误后停止并释放播放器，不再自动反复重新打开视频；按 ↓ 或设置中的重新读取项手动尝试。
- 收到系统低内存通知或采样发现系统处于低内存状态时，停止解码并释放播放器。
- 外挂字幕切换不再重建视频解码器，重复选择同一种解码方式也不重建。
- 异常中断的播放会话会保留标记，下次启动暂不自动播放，避免重复进入故障片段；按 ↓ 才手动恢复。
- 菜单显示系统可用内存、Java / 原生堆采样，以及接收速率、显示帧率和丢帧。堆采样不包含全部驱动 / 图形内存，不能单凭它证明没有内存问题。不记录影片内容或带签名的完整 URL。

整机重启的原因尚未确定。上述低内存处理依赖系统能及时通知应用，无法保证阻止驱动或内核故障；模拟器测试也不能代替海尔电视实测。若新版仍重启，需要设备系统日志进一步区分内存、解码驱动或其他系统问题。

电视 0% 时可手动选择“检测片源连接”；不再后台自动发起这项检测。检测仅请求前 64 KB 的 Range，读取一个字节后断开。它使用系统 HTTP 网络栈，与 LibVLC 网络栈可能不同；连接成功不证明持续传输、实际解码或电视稳定性通过。

## 视频与字幕地址

`movie.txt` 为 UTF-8，一行完整视频直链。支持 BOM、空行和 `#` 注释，多条时播放第一条；签名参数原样保留。读取文本失败后可以重试；视频开始播放后的内核错误会停止，菜单可手动重新读取并从头播放。

内嵌字幕和音轨会显示在相应菜单行，字幕可关闭、自动或指定轨道。

远程外挂字幕列表：`http://82.156.239.39/subtitle.txt`。每行写 `名称|字幕URL` 或只写字幕 URL：

```text
简体中文|http://82.156.239.39/subtitles/movie.zh.srt
English|http://82.156.239.39/subtitles/movie.en.vtt
双语|http://82.156.239.39/subtitles/movie.ass
```

在菜单刷新字幕列表，再到“外挂字幕”行切换。支持内核可识别的 SRT、VTT、ASS/SSA 等字幕，建议 UTF-8。一次选择一份外挂字幕，切换时不重建视频解码器。关闭外挂会关闭当前字幕，可再从字幕轨道行选择内嵌字幕。

也可通过系统文件选择器选电视或 U 盘里的字幕。系统选择器可能需要确定键；电视没有选择器时可使用远程列表。应用将你选择的字幕复制到私有目录（最大 8 MB），不申请整个存储空间的读取权限。

## 构建与验证

JDK 17、Android SDK 36、Gradle 8.11.1、AGP 8.9.2、LibVLC 3.7.7。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

模拟器测试用自生成的 HEVC Main10 10-bit + E-AC-3 5.1 测试片，验证 Surface 与 Texture 两种输出下的实际解码帧、显示帧、音频输出缓冲、外挂字幕选择与截图中的彩色画面，并验证方向键、前后台生命周期；声明自行处理方向、屏幕尺寸和输入设备配置变化，避免这些变化销毁重建播放界面。额外用自生成 3840×2160、24fps、HEVC Main10 + E-AC-3 的简单图形片进行超过 18 秒持续播放、无额外重建、低内存释放和不自动重试检查；另测异常会话不自动播放。合成片不能模拟原影片码率及复杂度，真实电视上的高分辨率性能仍需实测。

APK 为测试签名。CI 缓存签名；若缓存被清除导致签名改变，需卸载旧版后安装。发布版应使用自己的私有签名。

开源组件说明和源码位置见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。测试片来自 FFmpeg 的 `testsrc2` 和 `sine` 合成源，不含用户影片内容。
