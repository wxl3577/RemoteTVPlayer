# 远程电视播放器 1.2.1（老电视兼容版）

从 `http://82.156.239.39/movie.txt` 获取视频直链并自动播放。1.2.1 改用内置 LibVLC 3.7.7，包含 HEVC 与 E-AC-3 软件解码器，并通过 OpenSL ES 输出 PCM 音频。

## 安装包选择

- **RemoteTVPlayer-arm32.apk**：armeabi-v7a，优先供老款海尔等 32 位 ARM 电视尝试。
- **RemoteTVPlayer-arm64.apk**：arm64-v8a，供 64 位 ARM 设备使用。
- **RemoteTVPlayer.apk**：通用包，含 ARM32、ARM64、x86、x86_64，体积较大。

最低系统要求 Android 4.2 / API 17；APK 启用 V1（JAR）和 V2 签名。Android 4.2 以下、非安卓系统或不支持这些 CPU 架构的电视仍无法安装。电视型号未知时，不能保证一定适配。
下载 `.apk` 原文件后安装，不要把 Actions 下载的 ZIP 直接交给电视安装器。若仍提示“解析程序包时出现问题”，核对文件是否下载完整，以及电视“设置 → 关于本机”中的系统版本。发布页提供 SHA256 校验值。

## 遥控器

| 播放时按键 | 功能 |
| --- | --- |
| ↑ | 打开字幕、音轨与解码设置 |
| ↓ / 确定 | 暂停、继续 |
| ← / → | 快退、快进 10 秒，可长按 |
| 返回 | 关闭菜单或退出 |

菜单内 ↑ ↓ 选项目，← → 调整或执行；“返回播放”一行可以只用方向键退出菜单。菜单可上下滚动，小屏也能选到所有项目。

## 黑屏或没有声音时

设置菜单中的“解码方式”提供四个选项，并记住选择：

1. 自动（硬解优先）：由 LibVLC 尝试设备硬件解码；内核不支持时仍可能回退软解。应用不再因为缓冲超过 18 秒而重新打开视频并强制切软解。
2. 软件解码：使用内置解码器，适合系统不支持 HEVC Main10 / E-AC-3 的设备。
3. 软解 + Texture 画面输出：为部分 Surface 输出异常的设备提供另一条显示路径。
4. 仅硬件解码：不追加软件解码回退，4K 卡顿时优先尝试；电视不支持对应视频格式时可能播放失败。模式名称是所选策略，不代表已经确认使用了硬件解码。

菜单底部显示视频解码 / 显示帧数，以及音频解码 / 输出缓冲计数。字幕能显示不代表视频和音频已成功解码；这些计数能帮助定位问题。
PCM 音频输出不依赖电视或 HDMI 接收设备对 E-AC-3 直通的支持。软件解码仍受 CPU 性能限制，接近 4K 的 10-bit 视频可能卡顿；更换 1080p H.264 + AAC 片源是另一种兼容办法。

## 4K 卡顿、0% 与缓存

电脑 MPV 正常不等于安卓模拟器或旧电视具备相同的硬件解码能力。当前示例视频是约 27 GB、3832×1600、HEVC Main10 10-bit / E-AC-3，软件解码性能可能不足。仅硬解失败时，增加缓存不能补足硬件能力。

网络缓存可选 3 / 10 / 20 秒，默认 10 秒；切换后保留进度并重新缓冲。增加缓存用于减轻网络波动，会延长起播等待。缓存百分比表示播放前的缓冲进度，不是整部影片的下载比例。

设置底部显示片源读取速率（每秒接收字节计算的 Mbps）、当前显示帧率、累计丢帧、解码与输出计数。读速是播放器当前接收速率，缓存读满后可能归零，不是网速上限。

电视一直 0% 时，选择“检测片源连接”。播放器超过 20 秒没有读到字节也会自动检测一次。检测通过系统 HTTP 网络栈，只请求前 64 KB 的 Range、读取一个字节后断开；即使服务器忽略 Range，也不会下载完整影片。显示 HTTP 403、DNS、TLS 或超时等结果，不记录或展示带签名的完整片源地址。系统检测通过不代表 LibVLC 连接、持续传输或解码一定成功。请提供该行结果及底部帧数，便于进一步判断。

## 视频与字幕地址

`movie.txt` 为 UTF-8，一行完整视频直链。支持 BOM、空行和 `#` 注释，多条时播放第一条；签名参数原样保留。失败后自动重新读取，菜单也能手动重新读取并从头播放。

内嵌字幕和音轨会显示在相应菜单行，字幕可关闭、自动或指定轨道。

远程外挂字幕列表：`http://82.156.239.39/subtitle.txt`。每行写 `名称|字幕URL` 或只写字幕 URL：

```text
简体中文|http://82.156.239.39/subtitles/movie.zh.srt
English|http://82.156.239.39/subtitles/movie.en.vtt
双语|http://82.156.239.39/subtitles/movie.ass
```

在菜单刷新字幕列表，再到“外挂字幕”行切换。支持内核可识别的 SRT、VTT、ASS/SSA 等字幕，建议 UTF-8。一次选择一份外挂字幕，切换会重新缓冲并保留进度。

也可通过系统文件选择器选电视或 U 盘里的字幕。系统选择器可能需要确定键；电视没有选择器时可使用远程列表。应用将你选择的字幕复制到私有目录（最大 8 MB），不申请整个存储空间的读取权限。

## 构建与验证

JDK 17、Android SDK 36、Gradle 8.11.1、AGP 8.9.2、LibVLC 3.7.7。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

模拟器测试用自生成的 HEVC Main10 10-bit + E-AC-3 5.1 测试片，验证 Surface 与 Texture 两种输出下的实际解码帧、显示帧、音频输出缓冲、外挂字幕选择与截图中的彩色画面，并验证方向键和前后台生命周期。真实电视上的高分辨率性能仍需实测。

APK 为测试签名。CI 缓存签名；若缓存被清除导致签名改变，需卸载旧版后安装。发布版应使用自己的私有签名。

开源组件说明和源码位置见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。测试片来自 FFmpeg 的 `testsrc2` 和 `sine` 合成源，不含用户影片内容。
