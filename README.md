# 远程电视播放器 RemoteTVPlayer

Android TV / 安卓电视盒子全屏播放器，支持 Android 5.0（API 21）及以上。

启动后从 `http://82.156.239.39/movie.txt` 实时获取视频直链并自动播放。支持内嵌字幕、音轨切换、远程外挂字幕和本地外挂字幕。

| 播放时按键 | 功能 |
| --- | --- |
| ↑ | 打开字幕 / 音轨设置菜单 |
| ↓ | 暂停 / 继续 |
| ← / → | 快退 / 快进 10 秒，可长按 |
| 确定（可选） | 暂停 / 继续 |
| 返回 | 退出应用；菜单中则关闭菜单 |

菜单内：**↑ ↓ 选择项目，← → 切换选项或执行操作**。选择“返回播放”可只用方向键关闭菜单。菜单中也可重新读取视频并从头播放。

## 视频地址

`movie.txt` 保存一行完整视频直链（UTF-8），例如：

```text
https://your-video-server.example/movie.mp4?token=example
```

支持 BOM、空行、以 `#` 开头的注释，多条时播放第一条。签名查询参数原样保留。
APK 只内置文本地址，不内置你的迅雷签名直链；更新服务器文本后，下次打开应用或在菜单选择“重新读取视频”即可生效。
读取或播放失败按 5、10、20、30 秒间隔重试，之后每 30 秒重新读取。文本最大 64 KB，不使用文本缓存。

## 内嵌字幕和音轨

视频准备好后，菜单显示可解码的字幕 / 音轨。在相应行用左右键选择。
字幕有“关闭”“自动（优先中文）”和具体轨道；视频没有内嵌字幕时可添加外挂字幕。
“音轨”与“字幕轨道”分别选择。实际可用格式取决于 Media3 与电视解码器。

## 远程外挂字幕

把字幕文件上传到自己的服务器，在 `http://82.156.239.39/subtitle.txt` 写入字幕直链列表。
每行可为 `名称|完整字幕URL`，或只写完整 URL。例如：

```text
简体中文|http://82.156.239.39/subtitles/movie.zh.srt
English|http://82.156.239.39/subtitles/movie.en.vtt
双语|http://82.156.239.39/subtitles/movie.ass
```

在菜单选择“读取 / 刷新远程字幕列表”，再到“外挂字幕”一行用左右键选择。一次加载一份外挂字幕，切换时保留当前播放进度和暂停状态；会短暂重新缓冲。
支持 SRT、WebVTT、ASS/SSA、TTML；推荐 UTF-8 编码，文件地址应带正确扩展名，带签名参数也可以。复杂 ASS 特效与字体不保证完全还原。
列表最多 32 项；不存在 `subtitle.txt` 不影响正常视频、内嵌字幕或本地字幕。
选中外挂字幕后会自动选择对应字幕轨道；也可以在“字幕轨道”行切换或关闭。
若合并播放出错，会移除外挂字幕并重试视频，可在菜单重新选择字幕。

## 本地或 U 盘字幕

菜单中选择“选择电视或 U 盘中的字幕文件”，在系统文件选择器中选 SRT、VTT、ASS、SSA 或 TTML 文件。
系统文件选择器的操作取决于电视，可能需要遥控器确定键。若电视没有系统文件选择器，请用远程字幕列表。
只请求读取你选中的文件，不需要整个存储空间权限。上次选择的本地文件会保留在外挂字幕选项中，可再次选择。

## 安装与兼容性

在 **Releases** 下载 `RemoteTVPlayer.apk`，也可在 **Actions → Build APK → 成功运行 → Artifacts → RemoteTVPlayer-APK** 下载 ZIP 后解压。
使用 U 盘或 ADB 侧载到电视：

```sh
adb install -r RemoteTVPlayer.apk
```

当前是可直接安装的 debug 测试签名 APK。CI 缓存签名；缓存被清除后签名可能改变，此时需要先卸载旧版。正式分发请配置自己的私有 release 签名。

已验证示例视频地址可访问且支持 HTTP 分段读取，文件实际为 MKV / HEVC / E-AC-3。流畅度、音频和 HDR 支持需在电视上验证；迅雷签名失效后要更新 `movie.txt`。
支持 Media3 的 MP4、MKV、HLS、DASH 等媒体。HTTP 明文为给定服务器 IP 放行；其他远程服务器请使用 HTTPS。
切到后台停止播放并释放解码器；回到应用重新读取地址，同一视频恢复进度。没有广告或分析 SDK。

## 开发与检查

JDK 17、Android SDK 35、Gradle 8.11.1、AGP 8.9.2、Media3 1.5.1。

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
./gradlew connectedDebugAndroidTest
```

Actions 执行单元测试、Android Lint、APK 构建，以及模拟器菜单方向键和前后台生命周期检查。模拟器检查不等同于真实电视上的 HEVC / 音轨兼容性测试。
